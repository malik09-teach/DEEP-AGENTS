# S3 Examples

## Working with Amazon S3 using Boto3

### 1. Creating a Bucket
```python
import boto3

s3_client = boto3.client('s3', region_name='us-east-1')
bucket_name = 'deep-agents-storage-bucket'

s3_client.create_bucket(Bucket=bucket_name)
print(f"Bucket {bucket_name} created successfully.")
```

### 2. Uploading and Downloading Objects
```python
import boto3

s3_client = boto3.client('s3')

# Upload file
s3_client.upload_file(
    Filename='local_dataset.csv',
    Bucket='deep-agents-storage-bucket',
    Key='data/dataset.csv'
)

# Download file
s3_client.download_file(
    Bucket='deep-agents-storage-bucket',
    Key='data/dataset.csv',
    Filename='downloaded_dataset.csv'
)
```

### 3. Listing Objects in a Bucket
```python
import boto3

s3_client = boto3.client('s3')

response = s3_client.list_objects_v2(Bucket='deep-agents-storage-bucket', Prefix='data/')
for obj in response.get('Contents', []):
    print(f"Object: {obj['Key']} ({obj['Size']} bytes)")
```
