# AWS Skill

## Overview
Skill module for interacting with and managing Amazon Web Services (AWS) infrastructure and cloud resources.

## Scope & Capabilities
- **Compute**: EC2 instance provisioning, status monitoring, and lifecycle management.
- **Storage**: S3 bucket creation, object lifecycle, and access management.
- **Security & IAM**: Least privilege access policies, credential management, and role-based access.
- **Automation**: Infrastructure automation via `boto3` and AWS CLI.

## Related Files
- `instructions.md`: Guidelines and protocols for AWS resource operations.
- `best_practices.md`: Security, cost optimization, and reliability standards.
- `examples/ec2.md`: EC2 deployment and management examples.
- `examples/s3.md`: S3 operations and bucket policy examples.
