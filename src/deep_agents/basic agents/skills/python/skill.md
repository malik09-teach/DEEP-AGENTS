# Python Skill

## Overview
Skill module for Python development, data manipulation, standard library usage, and best engineering practices.

## Scope & Capabilities
- **Code Standards**: Writing idiomatic, clean Python compliant with PEP 8.
- **Data Engineering**: Data extraction, manipulation, and analysis using Pandas, NumPy, and Polars.
- **Testing & Quality**: Unit testing with `pytest`, type hinting with `mypy`, and code formatting.
- **Environment Management**: Dependency management using modern packaging tools (`uv`, virtual environments).

## Related Files
- `instructions.md`: Guidelines for writing modular, typed, and maintainable Python code.
- `examples/data_analysis.md`: Real-world data analysis and aggregation examples.
